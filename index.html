Data Management & Archive

Manage your Attendance App data carefully. Create an archive before resetting the application. Restoring an archive will replace the data currently saved in this browser.

1. Archive & Reset

Download a complete archive of your school profile, class schedules, student records, attendance records, email template and activity history. After the archive download is initiated, the app data saved in this browser will be cleared so you can start with a fresh database.

2. Restore from Archive

Select a previously downloaded Attendance App archive in JSON format. The archive will replace the data currently stored in this browser.

3. Delete All Permanently

This permanently deletes all Attendance App data saved in this browser without creating an archive. This action cannot be undone unless you have a separate backup file.
